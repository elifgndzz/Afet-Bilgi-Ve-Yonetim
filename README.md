# Afet-Bilgi-Ve-Yonetim
Bu proje JavaScript çerçeveleri React dersi için hazırlanmış bir web projesidir. Afet öncesi, sırası ve sonrasına yönelik; risk profil analizi, deprem çantası hazırlama sekmesi, toplanma alanları sorgulama ve mesafe hesaplama gibi kritik özellikleri barındıran kapsamlı bir afet bilgi yönetim sistemidir.
