# 🌋 Afet Bilgi ve Yönetim Platformu

Bu proje, **İstanbul Gelişim Üniversitesi Ön Yüz Yazılım Geliştirme Programı - JavaScript Çerçeveleri (React)** dersi kapsamında hazırlanan web projesidir. 

Platform; afet öncesi, sırası ve sonrasındaki kritik süreçleri dijitalleştirerek, toplumsal bilinci artırmayı ve afet anında doğru bilgiye hızlıca ulaşmayı amaçlar.

---

## 🚀 Öne Çıkan Özellikler ve Modüller

Proje, modern UI/UX prensiplerine uygun, kullanıcı dostu ve bento-box esintili dinamik bir arayüzle tasarlanmış olup şu ana modülleri içerir:

### ⏱️ 1. Evre Bazlı Bilgilendirme Sistemi (Öncesi - Sırası - Sonrası)
* **Afet Öncesi:** Alınması gereken tedbirler, yapısal risklerin azaltılması  rehberleri.
* **Afet Sırası:** Deprem, yangın, sel gibi farklı afet anlarında panik yapmadan uygulanacak doğru davranış modelleri (Çök-Kapan-Tutun vb.).
* **Afet Sonrası:** İlk saatlerde yapılması gerekenler, haberleşme yöntemleri ve ikincil risklerden korunma yolları.

### 📊 2. Dinamik Risk Profil Analizi
* Kullanıcıların girdikleri parametrelere (bina yaşı, zemin yapısı, kat planı vb.) göre kişiselleştirilmiş bir risk analizi sunar.
* Farklı afet senaryolarına karşı farkındalık yaratmak amacıyla hazırlanan dinamik değerlendirme aracı.

### 🎒 3. İnteraktif Afet Çantası Modülü
* "Afet çantamda neler olmalı?" sorusuna yanıt veren, kategorize edilmiş interaktif kontrol listesi (Checklist).
* Yiyecek, ilk yardım, giyecek ve önemli evraklar gibi kritik kategorilerde kullanıcının kendi çantasını hazırlarken ilerlemesini takip edebileceği fonksiyonel yapı.

### 📍 4. Toplanma Alanları 
* Kullanıcının konum bilgisine erişerek en yakın resmi acil durum toplanma alanlarını listeleme.
* Seçilen toplanma alanı ile kullanıcı arasındaki mesafeyi dinamik olarak hesaplayan ve rota entegrasyonuna zemin hazırlayan coğrafi modül.

## 🛠️ Teknolojik Altyapı

Projenin geliştirilmesinde performans, bileşen mimarisi ve temiz kod ilkeleri ön planda tutulmuştur:

* **Kütüphane:** React (Functional Components & Hooks)
* **Dil:** JavaScript (ES6+ ECMAScript standartları)
* **Tasarım & Styling:** Minimalist, temiz sans-serif tipografi (Inter fontu tercih edilmiştir) ve responsive (mobil uyumlu) modern layout.
* **Durum Yönetimi (State Management):** React Context API / useState / useEffect
